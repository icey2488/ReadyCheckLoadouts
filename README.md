# ReadyCheck Loadouts

A World of Warcraft retail addon that automatically displays your current spec, gear loadout, and talent loadout whenever a ready check fires — so your raid or group always knows what you're playing.

## Features

- Shows a draggable window on ready check with:
  - Your current spec icon and name
  - Active gear loadout (equipment set)
  - Active talent loadout
- Optionally announces your talent loadout in `/say` when a ready check fires
- Configurable per-content-type: toggle the window independently for raids and dungeons
- Closes automatically when you enter combat

## Usage

Type `/rcl` to open or close the options menu.

### Options

| Option | Default | Description |
|--------|---------|-------------|
| Show window during Raid | On | Display the loadout window when a ready check fires in a raid |
| Show window during Dungeon | On | Display the loadout window when a ready check fires in a dungeon |
| Output loadout in /say | On | Announce your talent loadout in /say on ready check |

## Installation

### Manual
1. Download the latest release
2. Extract the `ReadyCheckLoadouts` folder into your addons directory:  
   `World of Warcraft\_retail_\Interface\AddOns\`
3. Reload your UI or log in

### CurseForge / Wago
Install via the [CurseForge](https://www.curseforge.com) or [Wago](https://addons.wago.io) app and it will be kept up to date automatically.

## Compatibility

- Retail (The War Within)
